# Marketing Agent

Workspace for marketing work, built on the [marketingskills](https://github.com/coreyhaines31/marketingskills) skill library (48 skills) by Corey Haines.

## Skills

All 48 skills live in `.claude/skills/` and are available as project-level Claude Code skills: CRO, copywriting, SEO/AI-SEO, paid ads & ad creative, email/SMS, social, video, pricing, offers, onboarding, referrals, RevOps, sales enablement, PR, customer research, and more.

Start with `product-marketing` to set up positioning/ICP context (`.agents/product-marketing.md`), which the other skills reference.
